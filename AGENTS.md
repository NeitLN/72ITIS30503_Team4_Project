# Project agent instructions

For every frontend design or redesign task in this repository, use all three
design skills before acting, in this order:

1. `impeccable`
2. `frontend-design`
3. `superdesign`

Apply their guidance together when shaping, critiquing, auditing, polishing,
or otherwise changing the visual or interaction design. If their guidance
conflicts, preserve project requirements and accessibility first, then use
`impeccable` as the final quality rubric.
